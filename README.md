# Sudeste RP — Diretrizes Oficiais

Site estático pronto para publicação.

## Publicar no GitHub Pages
1. Crie um repositório público chamado `sudeste-rp`.
2. Envie todos os arquivos desta pasta para a raiz do repositório.
3. No GitHub, abra **Settings → Pages**.
4. Em **Build and deployment**, escolha **Deploy from a branch**.
5. Selecione a branch `main` e a pasta `/ (root)`.
6. Salve e aguarde a publicação.

O endereço padrão ficará no formato:
`https://SEU_USUARIO.github.io/sudeste-rp/`

O site é original e foi estruturado para o Sudeste RP, com identidade visual azul/preto e o logo fornecido.
